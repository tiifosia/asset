Gate.io · 토스증권 · 한국투자증권 ISA 자동화 설정 가이드

웹사이트에 접속하지 않아도 하루 1회 자동으로 잔고를 조회·누적합니다 (매매/출금 불가 · 100% 조회 전용)

1. Gate.io 읽기 전용 API v4 키 발급

Gate.io PC 웹 → 프로필 → API 관리(API Management) → API v4 키 생성에서 권한을 Wallet · Spot · Perpetual Futures = Read Only로만 체크하고, Trade(거래) 및 Withdraw(출금)는 반드시 해제하세요.

2. 토스증권 Open API 발급 및 고정 IP 등록

토스증권 PC 웹(WTS) → 우측 하단 설정 > Open API에서 client_id와 client_secret을 발급받은 뒤, 허용 IP 관리에 실행할 고정 IP(프록시 IP 등)를 등록하세요. 본 프로젝트의 수집 스크립트(scripts/fetch_portfolio.py)는 조회(GET) 엔드포인트만 호출하며 주문 API를 전혀 사용하지 않습니다.

3. 한국투자증권 Open API (중개형 ISA) 발급

한국투자증권 앱/홈페이지 → Open API (KIS Developers) 서비스 신청 시 중개형 ISA 계좌를 연결해 APP Key, APP Secret, 계좌번호(예: 12345678-01)를 준비하세요. 고정 IP 제한이 없으며 잔고 조회 전용(TTTC8434R)만 호출합니다.

4. GitHub Secrets에 키 등록 (안전한 암호화 저장)

GitHub 저장소 Settings → Secrets and variables → Actions → Repository secrets에 아래 값을 추가하세요:

GATE_API_KEY GATE_API_SECRET TOSS_CLIENT_ID TOSS_CLIENT_SECRET PORTFOLIO_PROXY_URL KIS_APP_KEY KIS_APP_SECRET KIS_ACCOUNT_NO

5. 선택지 2: 내 PC를 꺼둬도 365일 자동 실행 (무료 고정 IP 러너 / 프록시)

토스증권의 IP 허용 제한 때문에 무료 고정 IP 서버(예: Oracle Cloud Always Free VM 등)에 GitHub Self-Hosted Runner를 1회 설치한 뒤, GitHub 저장소 Variables에 RUNNER_LABEL = self-hosted를 설정하면 매일 06:30 KST(30 21 * * * UTC)에 고정 IP에서 자동으로 잔고를 조회해 페이지에 누적 반영합니다.
